Test-magic

Ein eigenständiges Browser-RPG-Projekt mit deutscher Spieloberfläche.

Ziel

Dieses Projekt entwickelt ein eigenes Fantasy-Browser-RPG mit:

* Charakteren
* Bewegung
* NPCs
* Quest-System
* Level-System
* Inventar
* Gegenständen
* Monstern
* einfachem Kampfsystem
* Login und Registrierung
* Speicherung der Charakterdaten

Sprache

Die Spieloberfläche ist vollständig auf Deutsch.

Die Begriffe Quest und Level bleiben genau so erhalten.

Alle NPC-Dialoge, Menüs, Meldungen, Gegenstände, Monster und Spieltexte werden für dieses Projekt eigenständig erstellt.

Start

Das Projekt verwendet zunächst Python und SQLite.

python server.py

Danach im Browser öffnen:

http://127.0.0.1:8000

Hinweis

Dieses Projekt ist eine eigenständige Neuentwicklung. Es enthält keinen originalen Quellcode, keine originalen SWF-Dateien und keine originalen geschützten Spiel-Assets von Magic Campus.
